# KeyboardMouse (キーボードマウス)

`KeyboardMouse` は、Windows環境においてキーボード操作のみでマウスカーソル移動、クリック、スクロールなどのマウス操作を実現する軽量な常駐型ユーティリティアプリケーションです。

---

## ✨ 主な特徴

- ⌨️ **キーボードで完全なマウス操作**: カーソル移動、左/中/右クリック、ホイールスクロールに対応。
- ⚡ **スムーズで緻密な移動**: デルタタイム計算と画面DPI取得により、ディスプレイの解像度に依存しないスムーズな移動（約125FPSタイマー駆動）を実現。斜め移動の速度補正や端数ピクセルの累積処理も完備。
- 🚀 **高速移動モード**: Shiftキーを押しながら操作することで、カーソル移動速度やスクロール量を4倍に加速。
- 🔔 **タスクトレイ＆通知連携**: タスクトレイに常駐し、機能のON/OFF状態をアイコン変化およびOSのトースト通知でお知らせ。
- 🛡️ **二重起動防止**: ミューテックス（Mutex）制御により、重複起動を防止。
- 🔕 **バックグラウンド動作**: タスクバーに表示されない不可視ウィンドウでバックグラウンド実行。

## 🎮 キー割り当て一覧

| 操作 | キー割り当て | 補足 / 追加説明 |
| :--- | :--- | :--- |
| **機能のON / OFF切り替え** | `Esc` | 機能をOFFにすると操作ログやキー状態がリセットされます |
| **カーソル移動（左）** | `←` または `J` | Shift同時押しで4倍速 |
| **カーソル移動（右）** | `→` または `L` | Shift同時押しで4倍速 |
| **カーソル移動（上）** | `↑` または `I` | Shift同時押しで4倍速 |
| **カーソル移動（下）** | `↓` または `K` | Shift同時押しで4倍速 |
| **左クリック** | `F` | 押下げで`LeftDown` / 離して`LeftUp`（ドラッグ可能） |
| **中クリック** | `G` | 押下げで`MiddleDown` / 離して`MiddleUp` |
| **右クリック** | `R` | 押下げで`RightDown` / 離して`RightUp` |
| **上スクロール** | `Y` | Shift同時押しでスクロール量4倍 |
| **下スクロール** | `H` | Shift同時押しでスクロール量4倍 |
| **加速（マルチプライヤー）** | `Left Shift` / `Right Shift` | 移動速度およびスクロール量を4倍にします |

## 🛠️ システム仕様・技術解説

- **言語・API**: C++ (Win32 API)
- **フック機構**: `SetWindowsHookEx` (`WH_KEYBOARD_LL`) による低レベルキーボードフックを使用。
- **タイマー処理**: 8ms（約125FPS）間隔でカーソル位置を更新。
- **移動計算**:
  - **基準速度**: 3.0 インチ/秒 （画面DPIを取得してピクセルへ換算）
  - **斜め移動補正**: `1 / sqrt(2) ≈ 0.7071` を適用し、斜め移動時の速度増加を防止。
  - **精度補正**: 1ピクセル未満の移動量を累積保持し、低速・微細な移動でもカーソルが引っかからないよう処理。

## 🚀 使い方

1. ビルドして生成された `KeyboardMouse.exe`（またはプロジェクト名 executable）を実行します。
2. タスクトレイにアイコンが追加され、自動的に機能が **ON** になります。
3. `Esc` キーを押すことで、いつでも機能の **ON / OFF** を切り替えられます。
4. アプリケーションを終了するには、タスクトレイのアイコンを右クリックし、「**終了(X)**」を選択します。
