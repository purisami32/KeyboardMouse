# KeyboardMouse (キーボードマウス)

`KeyboardMouse` は、Windows環境においてキーボード操作のみでマウスカーソル移動、クリック、スクロールなどのマウス操作を実現する軽量な常駐型ユーティリティアプリケーションです。

---

## ✨ 主な特徴

- ⌨️ **キーボードで完全なマウス操作**: カーソル移動、左/中/右クリック、ホイールスクロールに対応。
- 矢印キー・標準ショートカットの保全: 矢印キーによる通常のカーソル移動や、`Ctrl+C` / `Ctrl+V` / `Ctrl+F` などのショートカット操作を妨げずに透過（パススルー）可能。
- ⚡ **スムーズで緻密な移動**: デルタタイム計算と画面DPI取得により、ディスプレイの解像度に依存しないスムーズな移動（約125FPSタイマー駆動）を実現。斜め移動の速度補正や端数ピクセルの累積処理も完備。
- 🚀 **高速移動モード**: Shiftキーを押しながら操作することで、カーソル移動速度やスクロール量を4倍に加速。
- 🔑 **誤動作防止のショートカットトグル**: 誤操作を防ぐため、`Shift + Ctrl` の同時押しで機能のON/OFFを切り替え。
- 🔔 **タスクトレイ＆通知連携**: タスクトレイに常駐し、機能のON/OFF状態をアイコン変化およびOSのトースト通知でお知らせ。
- 🛡️ **二重起動防止**: ミューテックス（Mutex）制御により、重複起動を防止。
- 🔕 **バックグラウンド動作**: タスクバーに表示されない不可視ウィンドウでバックグラウンド実行。

## 🎮 キー割り当て一覧

| 操作 | キー割り当て | 補足 / 追加説明 |
| :--- | :--- | :--- | 
| **機能のON / OFF切り替え** | `Shift` + `Ctrl` | 同時押しで切り替え。OFFにすると押下状態や入力フラグが安全にリセットされます |
| **カーソル移動（左）** | `J` | Shift同時押しで4倍速 |
| **カーソル移動（右）** | `L` | Shift同時押しで4倍速 |
| **カーソル移動（上）** | `I` | Shift同時押しで4倍速 |
| **カーソル移動（下）** | `K` | Shift同時押しで4倍速 |
| **左クリック** | `F` | 押下げで `LeftDown` / 離して `LeftUp` |
| **中クリック** | `G` | 押下げで `MiddleDown` / 離して `MiddleUp` |
| **右クリック** | `R` | 押下げで `RightDown` / 離して `RightUp` |
| **上スクロール** | `Y` | Shift同時押しでスクロール量4倍 |
| **下スクロール** | `H` | Shift同時押しでスクロール量4倍 |
| **加速（マルチプライヤー）** | `Left Shift` / `Right Shift` | 移動速度およびスクロール量を4倍にします |

> **Note (透過キーの仕様)**: 
> - **矢印キー（`←` `→` `↑` `↓`）** はマウス操作から完全に独立しており、通常のキー入力として透過（パススルー）されます。
> - **`Ctrl + C` / `Ctrl + V` / `Ctrl + F`** などの組み合わせ入力も透過処理されるため、テキストのコピペや検索操作を阻害しません（キーボードマウス機能の `F` キー等の割り当てより優先して正常に動作します）。
> - その他の割り当てキー（`J`, `K`, `L`, `I`, `G`, `R`, `Y`, `H` 等）は、機能が **ON** の間のみフックされ、他アプリケーションへはブロックされます。

## 🛠️ システム仕様・技術解説

- **言語・API**: C++ (Win32 API / C++17)
- **フック機構**: `SetWindowsHookEx` (`WH_KEYBOARD_LL`) による低レベルキーボードフック。
- **タイマー処理**: 8ms（約125FPS）間隔の `WM_TIMER` で高頻度かつ滑らかにカーソル位置を更新。
- **移動計算**:
  - **基準速度**: 3.0 インチ/秒 （`LOGPIXELSX` より画面DPIを取得して自動ピクセル換算）
  - **斜め移動補正**: `1 / sqrt(2) ≈ 0.7071` を適用し、斜め移動時の速度倍増を防止。
  - **精度補正**: 1ピクセル未満の移動量を累積保持し、低速・微細な移動でもカーソルが引っかからない処理。
- **安全設計**: `std::atomic` によるスレッドセーフな状態管理、および機能OFF時のクリック保持自動解除処理を搭載。

## 🚀 使い方

1. ビルドして生成された `KeyboardMouse.exe` を実行します。
2. タスクトレイにアイコンが追加され、自動的に機能が **ON** になります。
3. `Shift` + `Ctrl` キーを同時に押すことで、いつでも機能の **ON / OFF** を切り替えられます。
4. アプリケーションを終了するには、タスクトレイのアイコンを右クリックし、「**終了(X)**」を選択します。
